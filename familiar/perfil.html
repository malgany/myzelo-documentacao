Configurações

Atualizar nome, contato e e-mail

Mantenha os dados de contato do responsável pela conta familiar.

Manual do familiar · Base visual: 07/10/2026 · Cadastro atualizado parcialmente em 24/10/2026 · Telas com dados fictícios

Objetivo: Mantenha os dados de contato do responsável pela conta familiar.

Antes de começar: Sessão iniciada na conta familiar.

Caminho: Meu perfil → Dados do perfil

Nesta página

  • Salvar dados pessoais
  • Quando você altera o e-mail
  • Qual cadastro você está alterando?
  • Resultado e regras

Salvar dados pessoais

  1. Abra Meu perfil e a aba Dados do perfil.
  2. Na seção Dados pessoais, confira Nome completo, E-mail e WhatsApp.
  3. Altere o que for necessário e clique em Salvar dados pessoais.
  4. Confira a mensagem de sucesso e os valores exibidos.

Quando você altera o e-mail

  1. Informe o novo endereço em E-mail e salve os dados pessoais.
  2. Abra a mensagem enviada ao novo endereço e clique em Verificar e-mail.
  3. Até confirmar, use o alerta do topo ou Reenviar e-mail no perfil se precisar de outra mensagem.

Alterar o e-mail remove a confirmação anterior. Você continua podendo salvar rascunhos, mas precisa confirmar o novo endereço para enviar novas solicitações.

Qual cadastro você está alterando?

Este formulário atualiza o responsável pela conta. Para alterar os dados de Helena, por exemplo, abra Pessoas assistidas. Para mudar o contratante ou endereço fiscal, use Dados fiscais.

Resultado esperado

Os dados da conta ficam atualizados; se o e-mail mudou, o novo endereço fica pendente de confirmação.

Regras que você precisa conhecer

  • Não é permitido usar um e-mail já cadastrado em outra conta.
  • O nome da pessoa marcada como titular acompanha o nome da conta.
  • Mudar o contato não muda os dados históricos de solicitações já enviadas.
